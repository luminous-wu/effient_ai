# 30-workflows — 可执行 SOP

"周一早上我打开电脑做什么"级别的步骤化流程。每个 SOP 必须可照做、有明确的
开始条件与完成判据，并标注哪些步骤需要人审（不可全自动）。

## SOP
- [[map-size-regression-sop]] — 版本 size 回归排查（脚本算数 → AI 假设 → 人审闸 → 确定性验证）
- [[linker-change-review-sop]] — 链接脚本变更评审（钉死方言 → Self-Critique → 清单人审 → 独立交叉验证）

## 约定
每个 SOP 必有：开始条件 / 步骤 / 完成判据 / **⛔ 不可全自动的点**。
⛔ 步骤是结构性的，不因"长期没事"放松（见 [[skill-atrophy-and-antipatterns]] §3）。
